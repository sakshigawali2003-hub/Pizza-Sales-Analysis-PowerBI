Pizza Sales Analysis – Power BI

Project Overview

This project analyzes pizza sales data using Microsoft Power BI to understand sales performance, customer preferences and business trends.

Objectives

- Analyze total revenue and total orders.
- Identify the best-selling pizza.
- Find the lowest-selling pizza.
- Analyze peak ordering hours.
- Compare pizza category and size performance.
- Generate meaningful business insights.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

Key Analysis

- Revenue Analysis
- Pizza Category Analysis
- Pizza Size Analysis
- Peak Hour Analysis
- Sales Performance Analysis
- Business Insights


Project Files

- Power BI Dashboard (.pbix)
- Dataset
- Dashboard Screenshot

Conclusion

This project provides insights into pizza sales performance and helps identify sales trends, popular products and business opportunities
